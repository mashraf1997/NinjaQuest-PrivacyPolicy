# Ninja Quest — Privacy Policy

The privacy policy for the **Ninja Quest** mobile application, ready to host as a public page (for example, the privacy-policy URL required by the Google Play listing).

## Files

- **`index.html`** — the formatted, responsive privacy-policy page (light & dark).
- **`privacy-policy.txt`** — the plain-text source.

## Publish with GitHub Pages

1. Go to **Settings → Pages**.
2. Under **Build and deployment**, set **Source** to *Deploy from a branch*.
3. Choose the default branch and the `/ (root)` folder, then **Save**.
4. Your policy will be available at `https://mashraf1997.github.io/NinjaQuest-PrivacyPolicy/`.

Use that URL as the privacy-policy link in your app store listing.

## Before publishing

Replace every `CONTACT_EMAIL` placeholder in `index.html` (and the `[mail]` placeholders in `privacy-policy.txt`) with the real contact email for the app.
